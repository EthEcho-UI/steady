# Steady

A calm to-do PWA for everyday habits and one-time tasks, ordered by importance.

- **Every day** tasks reset at midnight and show a streak.
- **To do** tasks: drag the dots (or focus them and press ↑/↓) to put the most important on top. The top one is marked *Start here*.
- **Focus** shows only the top task.
- Works offline and installs on phone and desktop.
- Data stays in your browser (localStorage). Use *⋯ → Download backup* to keep a copy or move it to another device.

Plain HTML/CSS/JS, no build step. Hosted on GitHub Pages.
